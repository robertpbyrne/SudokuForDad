# Sudoku para papá

[Elige un idioma](https://github.com/robertpbyrne/SudokuForDad/wiki)

## Guía del jugador

Sin anuncios. Sin presión. Solo Sudoku.

Creado para mi padre, Wayne, y para quienes disfrutan de un buen rompecabezas. Sudoku para papá te ofrece un espacio tranquilo para pensar, con un toque de humor al terminar.

• Nuevos rompecabezas cada día.
• Cuatro niveles de dificultad, desde relajados hasta exigentes.
• Un panel para las respuestas y otro para las notas a lápiz.
• Pistas cuando necesitas ayuda, o el modo Puro para jugar sin ayudas.
• Estadísticas y rachas diarias para seguir tu progreso.
• Una celebración al completar cada rompecabezas y un chiste de papá.

Dedícate un momento. Una casilla a la vez.

## Cómo jugar

Completa cada fila, columna y bloque de 3×3 con los dígitos del 1 al 9, sin repetirlos. Selecciona una casilla y usa el panel de bolígrafo para responder o el de lápiz para anotar posibilidades. En el modo Asistido puedes usar pistas.
