# Sudoku para Pais

[Escolha um idioma](https://github.com/robertpbyrne/SudokuForDad/wiki)

## Guia do jogador

Sem anúncios. Sem pressão. Só Sudoku.

Feito para meu pai, Wayne, e para quem gosta de um bom quebra-cabeça. Sudoku para Pais oferece um espaço tranquilo para pensar, com um pouco de humor no final.

• Novos quebra-cabeças todos os dias.
• Quatro níveis de dificuldade, dos mais tranquilos aos mais exigentes.
• Um painel de caneta para respostas e outro de lápis para anotar possibilidades.
• Dicas quando precisar, ou o modo Puro para jogar sem ajuda.
• Estatísticas e sequências diárias para acompanhar seu progresso.
• Uma comemoração ao terminar cada desafio e uma piada de pai.

Reserve um tempinho para você. Uma casa de cada vez.

## Como jogar

Preencha cada linha, coluna e bloco de 3×3 com os dígitos de 1 a 9, sem repetir. Selecione uma casa e use o painel de caneta para responder ou o de lápis para anotar possibilidades. As dicas estão disponíveis no modo Assistido.
